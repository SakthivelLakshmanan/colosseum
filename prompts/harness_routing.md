# Harness: write the routing query

You prepare a decision for routing. Read the decision brief and write a short **routing query**: a plain list of the topics this decision involves, so it can be matched against each adviser's capabilities by embedding similarity.

Rules:
- 5 to 12 short topic phrases, one per line, most important first.
- Use everyday business terms (for example "vendor contract terms", "where customer data is processed", "payment success rates", "migration effort", "fees and savings").
- Cover money, strategy, customers, contracts and regulation, security and data, and operations **only where the decision really touches them**. Don't pad.
- No names of advisers. No opinions. No numbers.
